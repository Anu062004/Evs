01 · Overview

What it is

A bird photograph goes in, and the three most likely species come out, each with a confidence score. The project has two parts.

  • Training pipeline. Python scripts that check the dataset, split it, fine-tune a ResNet-50 network and measure it on held-out photos.
  • Website. A Flask application that loads the trained model and identifies uploaded photos.

This is the Phase 1 baseline. Detecting several birds in one photo, rejecting unknown species, Grad-CAM explanations and biodiversity indices are planned for Phase 2 and are not built.

02 · Using the site

Identify a bird

  1. Open Identify and choose a JPG or PNG photo up to 10 MB.
  2. Press Identify.
  3. Read the three species and their confidence. The small photos are reference pictures of each species, so you can compare by eye.

Photos where the bird is large, sharp and unobstructed work best. Check the species list first: the model can only answer with one of those {{ species_count }} species.

03 · Data

Dataset and quality checks

The model was trained on 25 species from CUB-200-2011 (Caltech-UCSD Birds), 60 photographs per species. These are North American species; an Indian bird dataset can be run through the same scripts.

prepare_data.py does the following before any training:

  • Opens every file and rejects the ones that are corrupt.
  • Removes exact duplicate files.
  • Groups near-duplicate photos, such as resized copies, so a group never straddles two splits. This stops the model being tested on a photo it has effectively already seen.
  • Splits each species 70:15:15 into training, validation and test sets.
  • Writes the split manifest, a per-species count table and a log of rejected files.

The result was 1,050 training, 225 validation and 225 test photos. The dataset has no photographer or session information, so grouping by photographer was not possible; only near-duplicates are controlled.

04 · Training

How the model was trained

NetworkResNet-50 pretrained on ImageNet, final layer replaced with a 25-species layer
Input224 × 224 pixels, normalised with the ImageNet mean and standard deviation
AugmentationRandom crop, horizontal flip and colour jitter, on the training split only
Schedule15 epochs; the first 2 train only the new layer, the rest train the whole network
OptimiserAdamW with cosine learning-rate decay; cross-entropy loss with label smoothing 0.1
Model selectionThe epoch with the best validation macro-F1 is kept

The test split is used once, after training, on the selected weights. It plays no part in choosing them.

06 · Backend

What happens when you upload a photo

  1. The browser sends the file to /identify. Files over 10 MB, or files that are not images, are refused with a message.
  2. The photo is resized to 256 pixels on its short side, centre-cropped to 224 × 224 and normalised, the same steps used on validation photos during training.
  3. ONNX Runtime runs the network on the server's CPU and returns one score per species.
  4. Softmax converts the scores to percentages that add up to 100.
  5. The three highest are shown with their reference photos.

The model is trained in PyTorch and exported to ONNX, a portable format, so the website does not need PyTorch installed. Uploaded photos are processed in memory and are not saved. There is no database.

07 · Limitations

What to keep in mind

  • Closed set. A bird outside the {{ species_count }} species, or a photo with no bird at all, is still given one of those names.
  • Confidence is not certainty. A high percentage means the model prefers that species over the others it knows, not that the answer is verified.
  • One bird per photo. The whole image gets a single label.
  • Small test set. There are 9 test photos per species, so a single species' score shifts a lot with one mistake.
  • Curated photos. The dataset is mostly clear, well-framed pictures. Distant, dark or partly hidden birds will do worse.

08 · Run it yourself

Website

pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5000.

Retrain the model

Put the photos in data/raw, one folder per species, then:

pip install -r requirements-train.txt
python prepare_data.py --data-dir data/raw --max-classes 25
python train.py --manifest data/manifest/manifest.csv --data-dir data/raw
python export_onnx.py --weights runs/resnet50/best.pt

The source code is on GitHub.
